# AI 咨询会话列表布局设计

## 目标

调整 AI 咨询左侧栏的空间分配：将“常用问题”区域固定在侧栏底部，把可用的剩余高度交给会话列表，并让会话列表独立滚动。

## 交互与布局

- 左侧栏保持纵向布局，侧栏本身不承担滚动。
- 会话列表使用剩余高度，允许在会话数量较多时独立纵向滚动。
- “常用问题”标题及其按钮列表固定在侧栏底部，不随会话列表滚动。
- 能力说明继续位于常用问题区域下方，保持与底部内容的视觉分组。
- 会话列表项使用固定 `44px` 行高，标题和摘要超出时省略，不因填充列表剩余空间而变高。
- 会话列表项之间使用紧凑的底部分割线，保留当前条目的选中反馈。
- AI 会话、持仓诊断报告归档和趋势计算运行记录统一使用深色背景加左侧 `3px` 青绿色内阴影表示选中，不使用外框。
- 三处列表项的选中区域不使用圆角，背景覆盖列表项整行。
- 持仓诊断“报告归档”列表增加 `0 11px` 的水平留白，与趋势计算“运行记录”区域保持一致。
- 这三处列表暂不提供鼠标悬停反馈；其他控件的既有悬停反馈不在本次范围内。
- 窄屏布局继续使用现有双列提示面板，不改变会话选择、新建、删除和快速填充行为。

## 实现范围

- 修改 `frontend/src/views/AiConsultationView.vue` 的侧栏 DOM 分组和局部样式。
- 移除会话列表的固定最大高度，使用 flex 剩余空间和 `min-height: 0` 确保滚动边界正确。
- 为会话列表设置固定网格行规格和条目高度，使用列表项底部边框绘制分割线。
- 对齐三处列表的 active CSS 规则，并注释对应的鼠标悬停规则。
- 为底部常用问题区域增加不参与伸展的容器，并在窄屏布局中让它跨越整行。
- 不修改接口、状态管理、会话排序、确认删除或快速问题逻辑。

## 验收

- 会话较少时，常用问题区域仍固定在侧栏底部，会话区填充其上方空间。
- 会话较多时，只滚动会话列表，常用问题区域保持可见。
- 会话项保持 `44px` 高度，项间显示分割线，标题和摘要不会撑高条目。
- 窄屏下各区域不重叠，常用问题按钮仍可操作。
- 现有 AI 咨询测试通过，并补充布局结构断言以防止区域回退。
