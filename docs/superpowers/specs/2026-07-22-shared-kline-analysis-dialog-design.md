# 共享 K 线分析对话框设计

## 目标

将标的 K 线查看升级为可在自选、持仓及后续页面复用的分析对话框。对话框参考 Batman 的图表工作流，支持历史时间跨度、多个 MA 均线以及成交量和 MACD 副图切换，同时保持当前用户的数据隔离与行情源配置。

## 组件边界

- `InstrumentKLineDialog` 是唯一的 K 线交互入口。调用页面仅传入已选标的并处理关闭事件，不再自行请求 K 线或保存图表控制状态。
- 对话框内部从当前会话取得 token，请求历史行情和指标数据；自选、持仓、清仓及后续页面共享相同行为、错误状态和标题格式。
- 标题继续使用“`{名称} {代码} [{类型}]`”。对话框不包含标的检索、快速查看或新增自选控件。

## 控制与默认值

- 时间跨度提供 `半年`、`一年`、`两年`，分别请求约 120、250、520 个日 K 数据。默认 `半年`。
- MA 以多选分段控件提供 `5`、`10`、`20`、`30`、`45`、`60` 日周期；默认启用 `MA5`、`MA10`、`MA20`。
- 副图使用互斥分段控件：`MACD` 或 `成交量`。默认 `MACD`，与参考图一致。
- 主图固定为日 K，保留 ECharts 内置缩放、拖拽和十字光标；不提供重复的独立 Zoom 模式。
- 时间跨度、MA 选择和副图选择仅在当前打开的对话框生命周期内生效，关闭后恢复默认值。

## 数据与指标

- `POST /api/market/history` 增加受限的 `limit` 参数，默认 180，最大 640。后端行情适配层将该值传递给腾讯和东方财富历史接口，以满足两年日 K 的约 520 条需求。
- 前端 API 客户端同步支持 `limit`；共享组件在切换时间跨度时重新请求数据，不依赖前端裁剪 180 条旧数据。
- MA 在前端按已获取收盘价计算，每个启用周期生成独立线条与图例。
- MACD 调用既有本地 `IndicatorService`，渲染 DIF、DEA 与红绿柱；成交量模式渲染成交量柱。
- 无足够历史样本的 MA/MACD 值保持空值，不以零填充，避免产生误导线条。

## 异常与可访问性

- 时间跨度或指标请求失败时，对话框保留控制栏和当前成功图表，并在图表区域显示可理解的错误消息。
- 同一标的快速切换时间跨度时，只接受最后一次请求结果，避免较慢请求覆盖新选择。
- 所有分段控件使用原生按钮，提供选中状态与清晰标签；关闭按钮保留无障碍名称。

## 验收

- 自选、持仓和清仓名称打开的是同一共享 K 线分析对话框。
- 对话框支持半/一/两年数据范围、MA 多选、MACD/成交量切换，默认值符合本设计。
- 两年请求能获得超过 500 个日 K 的数据；行情源失败时显示错误而不泄露其他用户数据。
- 测试覆盖时间跨度映射、MA 计算、MACD 选择、限额校验和用户鉴权；前端 lint、测试、生产构建及浏览器验收通过。
