# 趋势策略子页面设计

## 目标

将趋势计算页面中的“新建策略”和“编辑策略”从右侧抽屉改为独立子页面。页面复用趋势策略的数据契约与指标目录能力，采用工作台式左右结构，使策略范围和指标参数可以同时编辑。

## 路由与导航

- 新建策略路由：`/analysis/trend/strategy/new`。
- 编辑策略路由：`/analysis/trend/strategy/:id`。
- 趋势计算工作台中的“新建策略”和“编辑策略”改为路由跳转，不再打开抽屉。
- 子页面顶部提供“返回趋势计算”按钮；浏览器后退与该按钮都返回 `/analysis/trend`。
- 保存成功后返回趋势计算，并在工作台重新读取策略列表、选中已保存策略及其运行记录。

## 页面布局

页面顶栏从左至右展示返回按钮、页面标题（新建趋势策略或编辑趋势策略）和保存策略按钮。

内容区为左右两栏：

- 左栏约占 39%，按“策略配置 → 数据与报告 → 标的范围”纵向排列。
  - 策略配置：名称、备注。
  - 数据与报告：目标范围、行情跨度、报告窗口。
  - 标的范围：占满左栏剩余高度。非全市场范围显示可滚动的标的表格；自定义范围可通过现有标的搜索组件添加或移除标的。
- 右栏约占 61%，上下分区。
  - 上半区是可分类折叠的指标库，支持添加、移除、说明展开、类别已选数量和全局展开/收起。
  - 下半区是已选指标及参数编辑器，随着已选指标变化即时更新；无参数指标保留默认计算参数说明。

左右各自维护滚动边界，页面不应因大量标的或指标导致主浏览器窗口失去可操作的保存与返回入口。

## 数据与交互

- 继续使用既有趋势策略 API 和 `TrendIndicatorDefinition` 目录；不改变策略、运行记录或报告数据格式。
- 保留当前指标的 `description`、`usageHint`、分类折叠和参数编辑体验。
- 新建时沿用默认 MA 与 MACD；编辑时加载该策略已有的范围、数据期间、报告窗口、指标及参数。
- 参数范围、最少一个指标和策略名称等校验由现有服务端约束兜底，前端给出即时可读错误提示。
- 删除策略仍从编辑页面提供，沿用统一确认对话框；不使用浏览器原生对话框。

## 测试与验收

- 路由测试覆盖新建、编辑与返回趋势计算。
- 组件测试覆盖子页面加载策略、添加/移除指标、折叠说明、保存成功后返回。
- 既有指标服务测试确认 26 个指标仍有分类、说明和使用提示。
- `bun run test` 与 `bun run build` 均需通过。
