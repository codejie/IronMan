# 桌面端二级菜单设计

## 范围

本次只调整桌面端菜单。移动端保持现状，不实现新的层级或抽屉交互，直到另行确认。

## 菜单结构

菜单取消分组标题，改为一级菜单与纵向二级链接。仪表盘为独立一级路由入口。其余一级菜单及二级项如下：

- 资产情况：自选、持仓、资金与流水。
- 行情数据：标的检索、市场概览、技术信号。
- 数据分析：技术图表、策略方案、分析任务、分析报告、AI 咨询、投资笔记。
- 系统设置：数据源、交易日、数据管理、AI 配置、定时任务、提醒告警、执行记录、个人与安全。
- 管理：用户与角色、审计日志、系统状态，仅管理员可见。

## 交互

一级菜单为手风琴触发器，仅负责展开或收起；二级项逐行纵向排列并负责路由跳转。当前路由所属一级菜单自动展开，当前二级项与所属一级菜单均有激活样式。现有路由地址、版本发布筛选和角色权限规则不变。菜单继续在独立滚动区内滚动。

## 实现与验收

将菜单模型改为嵌套树，并递归过滤不可见节点。侧栏根据节点是否拥有子项分别渲染路由链接或展开按钮。新增单元测试覆盖树形过滤、顺序和管理员节点；浏览器验收二级菜单纵向布局、展开/收起和激活状态。执行前端类型检查、测试和生产构建。
