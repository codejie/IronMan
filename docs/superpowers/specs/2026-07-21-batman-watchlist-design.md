# Batman 自选列表复刻设计

## 目标

将 `/assets/watchlist` 复刻为 Batman `/customized/list` 的桌面工作台：高密度行情表、持仓联动、目标价、刷新、历史数据开关，以及增加、快速查看和删除对话框。移动端不在本次范围。

## 界面与交互

- 顶部工具栏包含“增加自选”“快速查看”“使用历史数据接口”和“刷新”。
- 主表按顺序显示：序号、持有、类型、名称/代码、最新价/目标价/差值、昨收/今开、最高价/最低价/差值、涨跌幅/振幅、量比/换手率、操作。
- “持有”根据当前用户是否存在同标的活动持仓计算；主表不展示备注，但创建时继续保存备注。
- “增加自选”在对话框内搜索本地标的库后创建记录；“快速查看”选择标的后在对话框中展示 K 线；“设置目标价”和“删除”均使用独立确认对话框。

## 数据与接口

- 新增 `POST /api/assets/watchlist/workspace`，以 `{ refresh }` 请求完整自选工作台数据。
- 新增 `POST /api/assets/watchlist/update`，更新当前用户的目标价与备注；现有创建、列表、删除接口继续兼容。
- 工作台服务从用户配置的数据源读取日线，计算最新价、昨收、今开、最高/最低、涨跌、涨跌幅、振幅和目标价差值。量比为最新成交量与前五个交易日平均成交量之比；换手率没有可靠数据时为 `null` 并在界面显示 `-`。
- 刷新失败时保留已缓存的日线数据；没有缓存则返回空行情字段。现有 SSE 自选快照扩展为完整行情行，使前端无需自行拼接多个请求。
- 自选、持仓与目标价的读取和更新均按 `user_id` 过滤。HTTP 接口仅使用 POST，SSE 作为实时推送例外。

## 验收

- 后端测试先覆盖：行情字段计算、持仓联动、目标价更新、用户隔离、缓存降级和完整 SSE 快照。
- 前端测试覆盖工作台 API 与表格状态；桌面浏览器验证添加、刷新、快速查看、目标价更新和删除。
- `bun run test`、`bun run lint`、`bun run build` 和 `git diff --check` 均须通过。
