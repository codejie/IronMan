# Batman 持仓信息与子记录设计

## 范围

桌面端持仓页复刻 Batman `#/holding/list` 的工作流：资金信息汇总、持股记录宽表、展开式操作记录、增加持股、刷新、资金调整、详情、删除和清仓记录。父表不提供交易入口；买入、卖出、计息只在展开的子记录中维护。移动端不在本次范围。

## 界面

页面顶部展示总资产、可用资金及占比、成本及占比、本金、市场价值、盈亏和盈亏率。持股表提供展开箭头、类型、名称/代码、持仓/占比、成本/占比、均价/价差、现价/日期、涨跌、市场价值、盈亏、收益率和操作。展开行跨越父表列，显示“操作记录（n）”及按操作时间排序的子表。子表列为操作、数量、价格、费用、操作时间、备注和删除。

增加持股、增加操作、资金调整和删除确认均使用对话框；详情为独立记录详情视图；清仓记录可展开显示。刷新记录切换行情刷新，使用本地数据仅使用已缓存行情。父表操作只有详情和删除。

## 数据与接口

保留 `holdings` 作为父记录、`holding_transactions` 作为子记录。对外动作使用 `buy`、`sell`、`interest`，其中 `interest` 映射至现有数据库的 `dividend` 值并显示为“计息”。新增持仓工作区查询、子记录删除、父记录删除和资金调整接口，均为带 JSON body 的 `POST`。

迁移为资金流水增加子记录关联列。新增子记录先生成 ID，再在同一数据库事务中写入子记录与带该 ID 的资金流水；删除时移除对应流水、回滚现金并重新计算数量、成本、父记录状态和清仓归档。迁移同时按旧流水的持仓、动作、时间和金额回填可唯一匹配的历史关联。

工作区查询用当前用户的数据源取得或刷新每个标的的最新收盘价；市场价值为数量乘最新价，本金为资金调整流水净额，盈亏为总资产减本金。行情不可用时，相关字段显示为空值而不泄露其他用户数据。

## 验收

测试覆盖多用户隔离、子记录增删的资金回滚、卖出后清仓、计息、汇总计算和历史关联。浏览器验收父行展开、对话框、详情、删除确认、清仓显示和表格横向滚动；执行全量测试、类型检查和构建。
