# 趋势策略指标选择器设计

## 目标

将“趋势策略”新建/编辑抽屉中的平铺指标卡片替换为可分类、可折叠、可查看详情的选择器。用户应能快速浏览全部指标、理解指标用途，并在不离开策略编辑抽屉的情况下选择指标和配置参数。

本次只改变策略编辑体验，不改变策略、运行记录、报告或趋势计算的业务语义。

## 现状

- 后端 `trendIndicatorCatalog` 已提供 26 个指标、分类、参数范围、输出线与图表位置。
- 前端把目录渲染为平铺卡片；分类信息和输出线信息没有展示。
- 参数编辑位于指标目录下方，并已使用当前策略草稿的 `indicators` 数据结构。

## 数据契约

在既有目录项上新增展示元数据：

```ts
interface TrendIndicatorDefinition {
  id: TrendIndicatorId
  label: string
  category: TrendIndicatorCategory
  description: string
  usageHint: string
  parameters: TrendIndicatorParameter[]
  lines: string[]
  chart: "main" | "sub" | "hidden"
}
```

- `description` 说明指标的计算/识别对象。
- `usageHint` 说明适合观察的趋势、风险或形态信号。
- 后端目录接口继续由 `POST /api/analysis/trend/indicators/catalog` 提供，策略保存请求和既有指标选择结构保持不变。

## 分类与显示

分类名称与说明固定为：

| 分类 | 说明 |
| --- | --- |
| 覆盖研究 | 叠加在价格主图上的趋势或价格参考线 |
| 动量 | 趋势强度、方向和动量变化 |
| 波动率 | 波幅、价格通道与风险扩张 |
| 成交量 | 量能与资金流向 |
| 价格变换 | 由 OHLC 派生的价格参考值 |
| K线形态 | K线形态识别与反转提示 |
| 周期 | 主导周期和相位估计 |

每个分类面板标题显示：展开状态、分类名称、简短说明及“已选 n 项”计数。目录顶部提供“展开全部”和“收起全部”。

打开抽屉时，所有已选指标所属分类自动展开；覆盖研究、动量、波动率在没有已选项时默认展开；成交量、价格变换、K线形态和周期默认收起。折叠状态仅保存于当前编辑抽屉，不写入策略或浏览器存储。

## 指标交互

展开的分类中，每个指标行包含：

- 添加/已添加切换按钮；点击已添加会移除该指标。
- 指标简称和中文名称。
- 信息按钮；点击后在当前行下方展开详情，不打开新对话框。

详情内容包括用途说明、使用提示、图表位置、输出线和参数默认值/允许范围。图表位置映射为“主图”“副图”或“信号标记”。

选择与移除仍调用现有 `toggleIndicator` 行为；首次选择使用目录参数默认值。当前的“参数设置”区域继续展示所有已选指标，并是唯一可编辑参数的位置。移除指标时，其参数草稿一并移除。

## 可用性与布局

- 分类标题、添加/移除按钮和信息按钮均为原生 `button`，带清晰的 `aria-label` 与键盘焦点样式。
- 抽屉内容滚动，保存/删除操作栏保持固定。
- 指标说明与输出线在窄宽度下换行；指标名称不依赖悬停才能理解。
- 颜色仅辅助已选、折叠与图表位置状态，不作为唯一信息来源。

## 测试与验收

后端测试：

- 目录包含全部 26 个唯一指标。
- 每个指标包含有效分类、说明、使用提示、图表位置、参数范围与输出线。

前端测试：

- 分类正确分组，已选数量正确更新。
- 默认展开策略符合本规格，展开全部和收起全部可用。
- 点击添加/移除会保持现有草稿参数行为。
- 信息区域可独立展开/收起，显示图表位置、输出线和参数说明。
- 保存策略请求仍使用既有 `indicators` 契约。

验收命令：

```sh
bun run test
bun run build
```
