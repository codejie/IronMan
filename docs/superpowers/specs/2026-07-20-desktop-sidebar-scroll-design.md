# 桌面端侧栏滚动设计

## 范围

本次只实现桌面端。移动端抽屉导航作为后续需求记录，不实现也不纳入验收；之后的界面工作默认不处理移动端适配，除非另行确认。

## 布局

应用壳层固定为 `100dvh`，页面根节点禁止纵向滚动。桌面端维持固定宽度侧栏和右侧工作区：

- 侧栏使用三行网格：独立品牌区、可滚动主菜单区、固定用户与退出区。
- 品牌区包含 IronMan 标识，不随菜单内容移动。
- 菜单区使用 `overflow-y: auto` 与 `min-height: 0`，只能在自身区域滚动。
- 工作区使用 `overflow-y: auto` 与 `min-width: 0`，路由页面在其内部滚动。
- 两个滚动区使用 `overscroll-behavior: contain`，防止滚动边界传递到另一工作区。

## 交互与可访问性

现有路由、菜单高亮、登出行为和键盘焦点顺序保持不变。菜单链接取得焦点时，浏览器应自动在菜单滚动区内显示该链接。内容较长的表格与图表仍保持各自既有的横向或内部滚动能力。

## 验收

在典型桌面视口下验证：滚动菜单时品牌与用户区位置不变；滚动工作区时侧栏内容不移动；两个区域不会触发页面级纵向滚动；现有路由导航和登出功能正常。执行前端类型检查、测试与生产构建。
