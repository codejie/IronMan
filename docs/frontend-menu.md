# IronMan 前端菜单清单

## 导航原则

菜单面向个人投资者的高频操作，采用左侧分组导航与内容区工作台。视觉密度、表格、表单和状态反馈参考 [sub2api](https://sub2api-admin.enlhz.com/dashboard)，但不复制其业务语义。列表、详情、编辑和图表之间应就近跳转；持仓详情、K 线弹窗和编辑抽屉不增加独立一级菜单。

除登录页外，路由必须经过认证守卫。普通用户只看见自己的业务入口；管理员菜单只对 `admin` 角色显示，后端仍必须执行权限校验。

## 菜单行为约定

- 路由名称使用小写 kebab-case；页面标题使用中文业务名，避免沿用 Batman 中的 `sytem` 拼写。
- 任何资源详情页都从列表页携带资源 ID 进入，并在后端再次检查资源归属。
- “任务”“报告”“提醒”分别代表执行定义、计算产物和触发规则，避免概念重叠。
- 数据源、交易日和 AI 设置是用户级配置；全局默认值仅由管理员维护，用户可覆盖自己的偏好。
- P0/P1 之外的入口在对应功能上线前不显示；不以不可用菜单占位。

## 前端验收

每个菜单项需要有路由守卫测试、无权限直访测试和加载/错误/空状态。P1 通过后，用户应能从“标的检索”完成加入自选、建立持仓、查看 K 线和记录交易的闭环。P2 通过后，用户应能从“策略方案”创建计划，经“分析任务”查看进度，并在“提醒告警”看到对应触发记录。
